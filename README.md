# Excel Auto

初見の `.xlsx` を読み取り、入力資料から取得した値を安全な**入力候補**として表示・反映するローカルアプリです。

最初の版では、AIが不確かな推測でExcelを書き換えることを避けます。見出しの隣の空セルや、表の列見出しに一致する箇所だけを候補にし、数式セル・結合セル・保護セルは変更しません。

## 起動

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

ブラウザが開いたら、次の順に操作します。

1. `.xlsx` ファイルを投入する。
2. 入力データを文章、CSV、またはJSONで渡す。
3. 生成された候補を確認し、必要な候補だけ選ぶ。
4. `入力済みファイルを作成` を押して、元ファイルとは別のファイルをダウンロードする。

## 入力データの例

文章:

```text
請求先: 株式会社サンプル
請求日: 2026/10/02
担当者: 山田 太郎
```

JSON:

```json
{"請求先": "株式会社サンプル", "請求日": "2026/10/02"}
```

## 安全性

- 元ファイルを上書きしません。
- 数式、結合セル、保護済みシートのセルは変更対象外です。
- 提案内容・一致理由・自信度を、反映前に画面で確認できます。
- 書込み時は既存値があるセルを置き換えません。
